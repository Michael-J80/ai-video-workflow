# 即梦网页适配（alpha）

本版本已通过模拟网页测试，尚未完成真实官网扣费链路验证。`browser.example.json` 是需要填写的适配模板，不是宣称可用的官网选择器集合。缺少选择器、元素不唯一或核验不一致时，应用会停止而不是猜测点击。

1. 应用点击“打开浏览器登录”，手动登录专用 Chrome。其 profile 保存在 `data/browser-profile`，不会复制日常 Chrome 登录态。
2. 将 `browser.example.json` 复制为 `browser.local.json`。在专用浏览器开发者工具中检查当前网页的稳定属性。不要从网页复制脚本，也不要提供账号数据。
3. 为 `controls` 的模型、模式、分辨率、时长、画幅、数量填写 `read` 唯一选择器、`trigger` 展开控件和 `option` 目标选项选择器；`{value}` 被替换为任务目标值。原生 select 可直接选择可见标签。
4. `reference_count` 指向“全部(N)”或“图片(N)”的权威计数；本版本仅接收图片。`reference_items` 为按上传顺序排列的素材元素；悬停时从 `reference_name_attribute` 或 `reference_tooltip` 读取文件名。不得点击可拖拽缩略图。
5. `prompt`、`credits`、`balance` 必须分别唯一。报价/余额元素只能包含一个数值；包含总价与单价的整个面板不合格。`collapse` 为收起素材面板按钮，可留空。
6. `cards` 选择任务卡，`card_id_attribute` 必须是稳定且唯一的官网任务ID属性。`card_prompt`、`card_status`、`download` 相对于该卡；`success_labels` 是精确完成状态，不能用“包含完成”匹配“未完成”。网站不提供稳定任务识别时，不得启用自动恢复提交。
7. 重新启动应用。开始前手动创建空白生成页面，避免历史素材污染。先用不提交的准备阶段核对模型、样片模式、480P、1条、素材顺序、提示词全文及实际报价。只有用户在本地界面确认报价后才可能提交。

应用通过服务端绑定批准与设计、素材、参数及报价。Enter 前先持久化唯一提交意图；不明确时只查已生成记录，不自动再次按键。人工同时操作专用浏览器会影响证据，应在自动执行时避免修改页面。

`browser.local.json` 是操作者可信配置，不接收模型或网页动态写入。不能用它指向第三方网站。它和浏览器 profile 都被 Git 忽略。`test_mode` 只用于测试，不允许在正式应用启动配置中启用。
