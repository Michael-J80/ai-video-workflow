# 故障排查

> 排查前请确认：Windows 本地单用户、`127.0.0.1:8765`、不要对公网暴露；仓库不含登录态、素材、视频、模型、二进制或凭据。

## 启动与安装

- **`start.cmd` 无法启动**：确认 Python 3.12 在 PATH 中，已运行 `install.ps1`，；只有需要覆盖工具路径时才须从 `config.example.json` 复制配置。
- **端口占用**：默认 `127.0.0.1:8765`；若已有本应用运行，直接打开该地址；本版端口固定，不要关闭无关进程。
- **语音相关报错**：若未安装语音，系统应**显式 skip_speech**，这是预期行为而非失败。若要启用：
  - CPU：`install-speech.ps1 -Device cpu`
  - CUDA：`install-speech.ps1 -Device cuda`；**CUDA 不自动回退到 CPU**，失败即失败。

## 浏览器与真实页面

- **无法进行真实生成 / 提示选择器为空**：`browser.example.json` 是**空选择器模板**，必须复制为 `browser.local.json` 并按 `docs/browser-adapter.md` 配置。
- **即梦真实页面选择器**：**尚待核实**，需自行核对页面结构后填写；未核实前属于 UNVERIFIED，不代表失败也不代表通过。
- **登录失效**：使用 `POST /api/browser/login` 重新登录。仓库不保存登录态。

## 设计与计划

- **Codex 设计失败**：确认 Codex CLI 使用**订阅 ChatGPT 登录**，且**未**依赖 OpenAI API Key。Codex 账号协议检查本机已通过。
- **Hermes 计划异常**：确认 Hermes 配置了自己的 DeepSeek 凭据；计划阶段为**无工具**。Hermes CLI 已实际返回受限四步计划，模型返回不符合契约时会停止，而不是自动放宽规则。

## 报价与批准

- **批准无效/已过期**：批准有效期 **10 分钟**，且仅绑定**当前设计 hash + 素材 hash 顺序 + 参数 + 报价**。任一变化需重新报价并重新批准一次。
- **点击执行后无响应**：先检查 SQLite 是否已记录 `attempted`。流程要求**先记录 `attempted` 再执行 Enter**。
- **结果不明**：**只查不重提**。重复提交可能造成重复扣积分。
- **暂停/停止的语义**：停止**不撤销**官网已扣的任务。

## 媒体与文件

- **下载后文件异常**：确认 FFmpeg/ffprobe 可用；下载流程执行**技术/内容分离**，请分别核对。
- **`GET /api/tasks/{id}/files/path` 取不到文件**：确认路径在允许范围内，且文件确实已由流程写出。

## 状态语义

- 见到 **UNVERIFIED**：这是未知状态，**不是失败也不是通过**。
- 真实扣积分链路**尚未验证**；不要据此处文档推断“已可全自动真实生成”。
