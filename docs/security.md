# 本机运行边界

服务仅绑定 `127.0.0.1:8765`，校验 Host、Origin、会话 cookie 和写请求 CSRF token。不要通过反向代理开放到公网。文件下载只能访问当前任务已登记产物，HTML 产物以附件下载。

Codex 通过 ChatGPT 登录的 app-server 返回设计；请求 read-only sandbox、never approval，并关闭 shell/web search。Hermes 使用 safe-mode 与解析为空的 `workflow_no_tools` 工具集，只输出受限计划。程序拒绝工具调用事件和提交动作，网页按钮由宿主执行。这是个人本机应用的权限约束，不是对恶意本地程序的操作系统沙箱。

依赖 CLI 版本变化可能改变工具集或协议行为。升级后先验证非付费链路；不得启用 yolo、无约束 shell 工具或把整个用户目录交给代理。用户需求、网页文字、模型输出均视为数据。账号登录数据与密钥仅留在本机已有配置，不打包、不上报。

暂停在当前阶段结束后生效，无法撤销官网已提交的任务或扣费。遇到提交结果不明，保留证据并人工核对；不清空 attempted 标志“修复”任务。需重新生成时建立新任务并重新批准费用。

报告问题时先删除日志中的个人路径、账号信息、素材和提示词中的隐私内容。不要上传 `data/`、`.env`、浏览器配置文件夹或原始账户诊断输出。
