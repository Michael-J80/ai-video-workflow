# 样片优先工作流

本项目延续 V7.2 的设计/执行分工，将文件交接和状态持久化放入本地应用。

1. 用户输入需求、时长、画幅与参考图顺序；Codex 生成设计、分镜和完整提示词。
2. 本轮 generation 默认 Seedance 2.5 样片、480P、1条；desired_generation 仅为最终目标，不覆盖本轮参数。用户明确覆盖优先。
3. Hermes/Flash输出受限准备计划，应用核实参数、逐张上传与核验参考图、填入全文提示词、读取实际报价。页面能力不符即停。
4. 用户确认当前报价，批准绑定设计版本、素材哈希/顺序、时长画幅与本轮参数。10分钟失效；修改设计清除旧报价和批准。
5. 应用在SQLite事务中保存提交意图、之前任务卡ID和余额，再收起素材面板并在提示词框按一次Enter。结果不明只查询，不重提、不自动重试。
6. 余额差与新任务卡共同确认提交；等待官网完成，下载原片，核验视频流、解码、哈希与本地分析。
7. 技术PASS与内容UNVERIFIED分别展示。人物、动作连续性、声音、口型和整体质量仍需视听证据；不因技术通过自动升级高清。
8. 交付后停止。用户需要重出样片时创建新任务，重新核价批准。字幕或其他后续修改不应无故重新生成视频。

网站积分与模型费用独立：无法获取的模型费用记UNKNOWN，不能用未扣网站积分推断模型免费。没有自动实现的审美验证不得写成PASS。
